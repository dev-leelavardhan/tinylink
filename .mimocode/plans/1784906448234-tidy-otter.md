# Plan: Registration Flow Hardening

## Goal

Bring the registration flow to spec compliance: password strength validation, Argon2 hashing, email normalization, PENDING_VERIFICATION status, OTP generation, and verification email sending.

## Changes Overview

### 1. Install argon2, remove bcrypt

- `pnpm remove bcrypt @types/bcrypt && pnpm add argon2`
- Update all imports in `user-register.service.ts` and `user-login.service.ts`

### 2. Password Strength Validation (DTO)

**File:** `src/users/dto/register-user.dto.ts`

Add regex checks to the password field:
- `/(?=.*[a-z])/` — lowercase
- `/(?=.*[A-Z])/` — uppercase
- `/(?=.*\d)/` — number
- `/(?=.*[!@#$%^&*()_+\-=\[\]{};':"\\|,.<>\/?])/` — special character

Also add `.trim().toLowerCase()` transform to the email field.

### 3. Add Argon2 Constants

**File:** `src/users/constants/user.constants.ts`

- Rename `BCRYPT_ROUNDS` → `ARGON2_TIME_COST`, `ARGON2_MEMORY_COST`, `ARGON2_PARALLELISM`
- Add OTP constants: `OTP_LENGTH`, `OTP_EXPIRY_SECONDS`, `OTP_KEY_PREFIX`
- Add mailer constants: `SMTP_HOST`, `SMTP_PORT`, `MAIL_FROM`, `VERIFY_EMAIL_SUBJECT`
- Add error messages for new flows

### 4. Create Mailer Module (new)

Follow REFACTOR_RULES folder structure. Create `src/mailer/`:

```
src/mailer/
├── mailer.module.ts
├── mailer.service.ts
├── mailer.service.spec.ts
├── constants/
│   └── mailer.constants.ts
├── types.ts
```

- `mailer.service.ts`: Injectable service wrapping nodemailer
  - `sendMail(to, subject, html)` method
  - Uses `MAILER_HOST`, `MAILER_PORT`, `MAILER_USER`, `MAILER_PASS` from env via ConfigService
- `mailer.module.ts`: Exports `MailerService`
- Uses `PinoLogger` for logging

### 5. Create OTP Service (new, inside users module)

Create `src/users/use-cases/user-otp.service.ts`:

- `generate(userId, email)` → generates 6-digit numeric OTP, stores in Redis with TTL, returns OTP
- `verify(userId, otp)` → checks OTP against Redis, deletes on success
- Uses `RedisService` with `setex` / `get` / `del` for storage
- Key pattern: `otp:verify:{userId}` → stores hashed OTP + email

Also create `src/users/utils/otp.utils.ts`:
- `generateOtp(length: number): string` — cryptographically random numeric string

### 6. Update Register Service

**File:** `src/users/use-cases/user-register.service.ts`

Current flow: hash → create → generate tokens

New flow:
1. Hash password with argon2
2. Normalize email (already in DTO)
3. Create user with `status: PENDING_VERIFICATION`
4. Generate OTP via `UserOtpService`
5. Send verification email via `MailerService`
6. Generate and return auth tokens (user gets tokens but can't do much until verified)

### 7. Update Login Service

**File:** `src/users/use-cases/user-login.service.ts`

- Replace `bcrypt.compare` with `argon2.verify`
- Replace `bcrypt` import with `argon2`
- User should NOT be able to log in if `status === 'PENDING_VERIFICATION'` — add check (currently only checks `ACTIVE`)

### 8. Update User Repository

**File:** `src/users/repositories/user.repository.ts`

- Add `updateStatus(id, status)` method for future use by verification endpoint

### 9. Update Users Module

**File:** `src/users/users.module.ts`

- Import `RedisModule` (for OTP storage)
- Import `MailerModule`
- Add `UserOtpService` to providers
