### BUG-003: OTP reuse after Redis delete failure
**File**: `src/users/use-cases/user-otp.service.ts:189-204`
**Fix**: In `deleteOtp()`, mark the OTP as used in DB FIRST, then delete from Redis. This ensures even if Redis delete fails, the DB fallback path won't find a valid OTP.
```typescript
private async deleteOtp(userId: string): Promise<void> {
    // Mark as used in DB FIRST (prevents reuse via Redis fallback)
    try {
        await this.userRepository.markOtpUsed(userId);
    } catch (err: unknown) {
        this.logger.error({ err, userId }, 'Failed to mark OTP as used in DB');
    }
    // Then delete from Redis
    try {
        const key = `${USER_CONSTANTS.OTP_KEY_PREFIX}${userId}`;
        await this.redis.del(key);
    } catch {
        // Redis unavailable — DB record already marked as used
    }
}
```

### BUG-004: Race condition in anonymous URL rate limiting
**File**: `src/urls/use-cases/url-create.service.ts:160-177`
**Fix**: Combine check and increment into a single atomic operation using Redis INCR:
```typescript
private async checkAnonymousRateLimit(ip: string): Promise<void> {
    const key = `${USER_CONSTANTS.RATE_LIMIT_KEY_PREFIX}${ip}`;
    const count = await this.redis.incr(key);
    if (count === 1) {
        await this.redis.expire(key, USER_CONSTANTS.RATE_LIMIT_TTL_SECONDS);
    }
    if (count > USER_CONSTANTS.ANONYMOUS_URL_LIMIT) {
        throw new ForbiddenException(USER_ERROR_MESSAGES.FREE_LIMIT_REACHED);
    }
}
```

### BUG-011: OTP attempts counter is not atomic
**File**: `src/users/use-cases/user-otp.service.ts:251-293`
**Fix**: Use INCR atomically for attempts tracking:
```typescript
private async checkAttempts(userId: string): Promise<boolean> {
    const attemptsKey = `otp:attempts:${userId}`;
    try {
        const count = await this.redis.get(attemptsKey);
        const current = count ? parseInt(count, 10) : 0;
        return current < USER_CONSTANTS.OTP_MAX_ATTEMPTS;
    } catch {
        return true;
    }
}

private async incrementAttempts(userId: string, success: boolean): Promise<void> {
    const attemptsKey = `otp:attempts:${userId}`;
    try {
        if (success) {
            await this.redis.del(attemptsKey);
        } else {
            const count = await this.redis.incr(attemptsKey);
            if (count === 1) {
                await this.redis.expire(attemptsKey, USER_CONSTANTS.OTP_EXPIRY_SECONDS);
            }
        }
    } catch {}
}
```

### BUG-013: Hash short code generator has modulo bias
**File**: `src/common/short-code/generators/hash.generator.ts:34`
**Fix**: Use rejection sampling:
```typescript
private getValidIndex(byte: number): number {
    // 256 % 62 = 8, so bytes 0-247 are uniform, 248-255 retry
    if (byte < 248) return byte % 62;
    return -1; // Retry signal
}

generate(options: ShortCodeGenerateOptions): string {
    const attempt = options.attempt ?? 1;
    const payload = `${options.originalUrl}\0${attempt}`;
    const digest = createHash('sha256').update(payload).digest();
    const { RANDOM_BASE, RANDOM_BASE_LENGTH } = RANDOM_BASE_CONSTANTS;

    let result = '';
    let i = 0;
    while (result.length < this.length) {
        if (i >= digest.length) {
            // Extend digest if needed
            break;
        }
        const idx = this.getValidIndex(digest[i]);
        if (idx !== -1) {
            result += RANDOM_BASE[idx];
        }
        i++;
    }
    return result;
}
```

### BUG-014: Snowflake generator uses busy-wait loop
**File**: `src/common/short-code/generators/snowflake.generator.ts:75-80`
**Fix**: Use `Atomics.wait` for non-blocking wait:
```typescript
private waitNextMillis(lastTimestamp: bigint): bigint {
    let timestamp = this.currentTimestamp();
    while (timestamp <= lastTimestamp) {
        Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 1);
        timestamp = this.currentTimestamp();
    }
    return timestamp;
}
```

### BUG-022: OTP hash uses unsalted SHA-256
**File**: `src/users/use-cases/user-otp.service.ts:305-307`
**Fix**: Add per-OTP salt:
```typescript
private hashOtp(otp: string, salt?: string): { hash: string; salt: string } {
    const actualSalt = salt || randomBytes(16).toString('hex');
    const hash = createHash('sha256').update(`${otp}:${actualSalt}`).digest('hex');
    return { hash, salt: actualSalt };
}
```
Note: This requires schema changes to store salt alongside hash.
