# Plan: Logout Production-Grade Improvements

## Overview

Add `POST /auth/logout-all` endpoint (revokes ALL sessions including current), fix response messages to match guide, and ensure both logout-all variants are available.

---

## 1. Add `POST /auth/logout-all` endpoint

**Problem:** Guide specifies `POST /auth/logout-all` but it doesn't exist. Current `DELETE /sessions` revokes all EXCEPT current.

**Files:**
- `server/src/users/controllers/auth.controller.ts` — add new endpoint
- `server/src/users/use-cases/user-login.service.ts` — add `logoutAll()` method that revokes ALL sessions
- `server/src/users/service/users.service.ts` — add facade method

**Changes:**

1. Add `logoutAll()` to `user-login.service.ts`:
   ```ts
   async logoutAll(
     userId: string,
     ip: string | undefined,
     userAgent: string | undefined,
   ): Promise<void> {
     const result = await this.sessionRepository.revokeAllForUser(userId);

     await this.auditService.logGlobalLogout(
       userId,
       { revokedCount: result.count },
       ip,
       userAgent,
     );

     this.logger.info(
       { userId, revokedCount: result.count },
       USER_LOG_MESSAGES.GLOBAL_LOGOUT,
     );
   }
   ```

2. Add facade method to `users.service.ts`:
   ```ts
   logoutAll(userId: string, ip: string | undefined, userAgent: string | undefined): Promise<void> {
     return this.loginService.logoutAll(userId, ip, userAgent);
   }
   ```

3. Add controller endpoint to `auth.controller.ts`:
   ```ts
   @Post('logout-all')
   @UseGuards(JwtAuthGuard)
   @HttpCode(HttpStatus.OK)
   async logoutAll(
     @Req() req: Request,
     @Res({ passthrough: true }) res: Response,
   ): Promise<{ message: string }> {
     const userId = (req.user as { userId: string })?.userId;
     const ip = getClientIp(req.headers, req.ip);
     const userAgent = req.headers['user-agent'];

     await this.usersService.logoutAll(userId, ip, userAgent);
     clearRefreshTokenCookie(res);

     return { message: 'Logged out from all devices successfully.' };
   }
   ```
