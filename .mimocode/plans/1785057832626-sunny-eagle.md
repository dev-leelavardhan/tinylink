# Production-Grade JWT & Session Management

## Overview

Add 6 missing production features to the auth module: refresh token reuse detection, atomic refresh rotation, JWT issuer/audience validation, global logout, periodic session cleanup, and password change with session revocation.

---

## Feature 1: Refresh Token Reuse Detection

**Goal:** If an old refresh token is presented after rotation, assume token theft → revoke all sessions, audit the event.

### Files to modify

**`prisma/schema.prisma`** — Add to `AuditEvent` enum:
```
REFRESH_TOKEN_REUSE
GLOBAL_LOGOUT
PASSWORD_CHANGED
```

**`src/common/audit/audit.service.ts`** — Add to `AuditEvent` type union:
```
| 'REFRESH_TOKEN_REUSE' | 'GLOBAL_LOGOUT' | 'PASSWORD_CHANGED'
```

**`src/users/repositories/session.repository.ts`** — Add method:
```typescript
findRecentlyRevokedByUserId(userId: string, since: Date): Promise<Session[]>
```

**`src/users/use-cases/user-login.service.ts`** — In `refresh()`, when `findByRefreshTokenHash` returns null:
- Query `findRecentlyRevokedByUserId(userId, 5_minutes_ago)`
- If match found → theft: `revokeAllForUser(userId)`, audit `REFRESH_TOKEN_REUSE`

**`src/users/constants/user.constants.ts`** — Add:
```
REFRESH_TOKEN_REUSE_DETECTED: 'Security violation: refresh token reuse detected'
```

## Feature 2: Atomic Refresh Token Rotation

**Goal:** Wrap old session revocation + new session creation in a Prisma transaction.

### Files to modify

**`src/users/repositories/session.repository.ts`** — Add method:
```typescript
rotateSession(oldSessionId: string, newSessionData: Prisma.SessionCreateInput): Promise<Session>
```
Uses `this.prisma.$transaction([revoke old, create new])`.

**`src/users/use-cases/user-login.service.ts`** — In `refresh()`, replace separate revoke + create with `rotateSession()`.

## Feature 5: Periodic Session Cleanup

**Goal:** Scheduled BullMQ job to delete expired + old revoked sessions.

### New files (follow AnalyticsCleanupScheduler pattern)

| File | Purpose |
|------|---------|
| `src/users/queue/session-cleanup.queue.ts` | BullMQ Queue (`users-cleanup`) |
| `src/users/queue/session-cleanup.worker.ts` | BullMQ Worker, handles `cleanup` job |
| `src/users/queue/session-cleanup.scheduler.ts` | `OnModuleInit`, adds repeatable cron job |
| `src/users/use-cases/session-cleanup.service.ts` | Calls `deleteExpired()` + `deleteRevokedOlderThan()` |

### Modified files

**`src/users/repositories/session.repository.ts`** — Add:
```typescript
deleteRevokedOlderThan(date: Date): Promise<Prisma.BatchPayload>
```

**`src/users/constants/user.constants.ts`** — Add queue constants:

**`src/users/users.module.ts`** — Add providers: `SessionCleanupQueue`, `SessionCleanupWorker`, `SessionCleanupScheduler`, `SessionCleanupService`.
