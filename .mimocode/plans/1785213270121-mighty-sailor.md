# Plan: Migrate to Url + Identifier Data Model

## Overview

Replace the current model (Url owns shortCode + customAlias + UrlSlug) with the proposed model (Url = destination, Identifier = every redirectable code with kind/owner/expiration/state/strategy).

---

## Final Schema

### IdentifierKind (enum)
```prisma
enum IdentifierKind {
  GENERATED
  CUSTOM_ALIAS
}
```

### IdentifierStrategy (enum)
```prisma
enum IdentifierStrategy {
  RANDOM
  HASH
  SNOWFLAKE
  SEQUENTIAL
  MANUAL
}
```

### Url
```prisma
model Url {
  id            String   @id @default(cuid())
  originalUrl   String   // user display (preserves full URL with params)
  normalizedUrl String   @unique // dedup key (stripped of trailing slash, params, etc.)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt

  identifiers Identifier[]
  analytics   Analytics[]
}
```

### Identifier
```prisma
model Identifier {
  id         String              @id @default(cuid())
  code       String              @unique
  kind       IdentifierKind
  strategy   IdentifierStrategy? // which generator created this code

  urlId      String
  ownerId    String?             // NULL = guest, UUID = user-owned

  expiresAt  DateTime?
  disabled   Boolean             @default(false)
  deletedAt  DateTime?           // soft delete

  createdAt  DateTime            @default(now())
  updatedAt  DateTime            @updatedAt

  url   Url   @relation(fields: [urlId], references: [id], onDelete: Cascade)
  owner User? @relation(fields: [ownerId], references: [id], onDelete: SetNull)

  analytics Analytics[]

  @@index([urlId])
  @@index([ownerId])
  @@index([ownerId, kind, urlId])  // user dashboard + dedup lookup
  @@index([expiresAt])
  @@index([deletedAt])
}
```

### Analytics (modified)
```prisma
model Analytics {
  id           String    @id @default(cuid())
  identifierId String    // primary: per-link tracking
  urlId        String    // denormalized: fast aggregate queries

  timestamp    DateTime  @default(now())
  browser      String?
  os           String?
  device       String?
  country      String?
  city         String?
  ipHash       String
  referrer     String?

  identifier Identifier @relation(fields: [identifierId], references: [id], onDelete: Cascade)
  url        Url        @relation(fields: [urlId], references: [id], onDelete: Cascade)

  @@index([identifierId])
  @@index([urlId])
  @@index([timestamp])
  @@index([urlId, timestamp])
  @@index([urlId, browser])
  @@index([urlId, country])
}
```

### User (add relation)
```prisma
model User {
  // ... existing fields ...
  identifiers Identifier[]
}
```

### Removed
- `UrlSlug` model — replaced by `Identifier`
- Columns removed from `Url`: `shortCode`, `customAlias`, `strategy`, `expiresAt`, `disabled`, `userId`, `deletedAt`, `lastAccessedAt`

---

## Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| `kind` (not `type`) | Enum | Avoids confusion with `strategy`; clear domain separation |
| `strategy` on Identifier | Optional enum | Track generator (RANDOM/HASH/SNOWFLAKE/SEQUENTIAL/MANUAL) for debugging |
| `normalizedUrl` | Unique on Url | Dedup key; `originalUrl` preserved for display (handles trailing slashes, params, www) |
| `disabled` on Identifier | Boolean | Disable individual identifiers without deleting |
| `deletedAt` on Identifier | Optional | Soft-delete preserves analytics history |
| Analytics | Both `identifierId` + `urlId` | Per-link tracking + fast aggregate queries (no join needed for totals) |
| Guest dedup | `ownerId IS NULL + kind=GENERATED + deletedAt IS NULL + disabled=false + (expiresAt IS NULL OR expiresAt > NOW())` | Guests reuse active guest identifiers; expired/disabled ones get new codes |
| Auth user dedup | `ownerId = user + kind=GENERATED + deletedAt IS NULL` | Each user gets their own generated identifier |

## Files to Change

### Prisma Schema & Migration

**`prisma/schema.prisma`** — Major rewrite:
- `Url` model: strip to id, originalUrl, normalizedUrl (unique), createdAt, updatedAt, relations
- New `IdentifierKind` enum, `IdentifierStrategy` enum
- New `Identifier` model with all fields above
- `Analytics` model: add `identifierId` FK + relation, keep `urlId` FK
- `User` model: add `identifiers` relation
- Remove `UrlSlug` model entirely

**New migration** — Direct schema rewrite (no production data to protect):
1. Rewrite `prisma/schema.prisma` with new models
2. `prisma migrate reset` — drops DB, recreates from scratch
3. `prisma migrate dev --name identifier-model` — creates clean migration
4. `prisma generate` — regenerate client
